# Формат проекта Graph3D v1

Файл `.graph3d` содержит JSON в UTF-8. Корневой объект содержит
`"format": "Graph3D"`, `"version": 1`, `"unit": "mm"` и массив `objects`.
Идентификаторы начинаются с 1 и идут по порядку. `visible` задаёт
видимость. Ссылки на исходные объекты указывают на более ранние
идентификаторы.

| Тип | Поля помимо `id`, `type` и `visible` |
|---|---|
| `primitive` | `kind` (cube, cylinder, sphere), `x`, `y` |
| `sketch` | `plane` (XY, XZ, YZ), массив `entities` |
| `extrude` | `profile`, `distance` со знаком |
| `revolve` | `profile`, `axis` (U или V), `offset`, `angle` в градусах |
| `boolean` | `first`, `second`, `operation` (union, difference, intersection) |
| `imported` | Имя `name` и геометрия `brep` в формате OCCT BREP v1, закодированная в Base64 |

У элементов эскиза `line` и `rectangle` есть координаты `a` и `b` в виде
пары `[u, v]`. У `circle` есть `center` и `radius`.

Проект хранит параметры и зависимости, а тела перестраиваются при открытии.
Ошибки параметров и блокировки тоже пересчитываются. Импортированная геометрия
встроена в проект, поэтому исходный файл STEP больше не требуется. Положение
камеры, незавершённый эскиз и шаги Undo/Redo в файл не записываются.

Проекты версии 1 читаются при размере до 64 МиБ. В одном проекте поддерживается
до 10 000 операций и до 10 000 элементов в одном эскизе. Неизвестные версии,
повреждённый JSON и некорректные ссылки отклоняются. Запись заменяет прежний
файл только после записи полного нового содержимого.

## Обмен моделями

| Формат | Что переносится | Ограничения |
|---|---|---|
| STEP (`.step`, `.stp`) | Точная геометрия видимых тел в миллиметрах | История Graph3D, эскизы и параметры остаются в проекте. При импорте сохраняются твёрдые тела, без структуры сборки, материалов и аннотаций. Файл импорта ограничен 64 МиБ |
| Бинарный STL (`.stl`) | Треугольная поверхность видимых тел. Координаты записываются в миллиметрах | В STL нет поля для единиц, дерева построения и точных кривых. В программе получателя при необходимости выберите миллиметры |

Скрытые объекты и эскизы пропускаются. Если у видимого тела есть ошибка
перестроения, его нужно исправить или скрыть. Для STL используется
триангуляция с линейным отклонением 0,05 мм и угловым 0,2 радиана.
Соприкасающиеся и пересекающиеся тела экспортируются как отдельные тела
или сетки. Для получения одного цельного тела сначала объедините их в Graph3D.
