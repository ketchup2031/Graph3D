# Graph3D

Graph3D — проект параметрической CAD-системы для механического проектирования.
Прототип показывает интерактивную 3D-сцену на базе Open CASCADE Technology (OCCT).
План следующих этапов приведён в [дорожной карте](Graph3D_Development_Plan.md).

## Установка на Windows

Откройте [Graph3D v0.1.0](https://github.com/ketchup2031/Graph3D/releases/tag/v0.1.0)
и скачайте `Graph3D-0.1.0-Windows-x64-Setup.exe` из раздела **Assets**.
Запустите установщик, затем откройте **Graph3D** через меню «Пуск». Мастер
также может создать ярлык на рабочем столе. Qt, OCCT и другие нужные
библиотеки входят в установщик. MSYS2 понадобится только для сборки из исходников.

Graph3D устанавливается для текущего пользователя. Его можно удалить через
список приложений в настройках Windows. Установщик этой версии не подписан.

## Стартовая страница

При запуске Graph3D открывается стартовая страница. В **Open** можно выбрать
файл или вернуться к одному из восьми недавних проектов. В **Create** доступны
пустая деталь, эскиз на XY и демонстрационный куб. Встроенные примеры показывают
виды детали и открываются для сохранения в новый файл.

Стартовая страница, детали и чертежи открываются во вкладках одного окна.
**File → Start page** возвращает к списку недавних файлов. Переключение вкладки
сохраняет её инструменты и историю отмены. Повторное открытие того же файла
переключает на его вкладку. Закрыть активный документ можно крестиком на
вкладке или **Ctrl+W**. Graph3D предложит сохранить изменения перед закрытием.

Автосохранение записывает локальную копию примерно через секунду после
изменения проекта или чертежа. При следующем запуске после сбоя выберите
**Restore**, чтобы открыть доступные копии во вкладках, или **Keep for later**,
чтобы вернуться к ним через **File → Recover documents…** на стартовой
странице. Восстановленные документы можно сохранить под выбранными именами.
В 3D сохраняются операции, добавленные в дерево модели.

В меню **Settings → Dark theme** можно переключить оформление. Graph3D
запоминает этот выбор при следующем запуске.

Английский интерфейс включён по умолчанию. Для русского языка выберите
**Settings → Language → Русский** и перезапустите Graph3D. Для возврата к
английскому используйте **Настройки → Язык → English**.

## Обмен DXF и DWG

- Откройте `.dxf` или `.dwg` через **Open** или **File → Import DXF or DWG…**.
  Для сохранения правок в Graph3D выберите `.g3draw`.
- **File → Export current sheet to DXF…** записывает выбранный лист в миллиметрах.
  **Export all sheets to DXF…** переносит листы на отдельные вкладки DXF. Передаются
  слои, простые блоки, редактируемые размеры, отрезки, дуги, окружности, полилинии,
  текст, штриховка ANSI31, сплошные, штриховые и осевые линии.
- **File → Export current sheet to DWG…** записывает активный лист в DWG 2000.
  Для работы с DWG установите GNU LibreDWG 0.14. Поместите `dxf2dwg` и `dwg2dxf`
  в папку из `PATH` или укажите её в переменной `GRAPH3D_LIBREDWG_DIR`, затем перезапустите Graph3D.
- Отчёт показывает количество пропущенных объектов и свойств по типам. Для точной
  передачи печатного оформления используйте PDF. [Описание форматов](docs/project-format.md#обмен-dxf-dwg-и-автосохранение)

## 3D-сцена

- В меню **Create** можно добавить куб, цилиндр или сферу. Новые тела
  располагаются рядом друг с другом.
- Левый щелчок выбирает тело, правая кнопка вращает камеру, средняя перемещает
  её, колесо масштабирует. Клавиша **F** показывает все тела.
- В меню **View** доступны стандартные виды, оси и сетка.
- **File → New scene** очищает сцену. **Help → Open log folder** открывает журнал.

Для сохранения сцены используйте **File → Save project**.

## Эскизы и моделирование

1. В **Sketch** выберите плоскость XY, XZ или YZ. На ней U — горизонтальная
   координата, V — вертикальная. Сетка привязывает точки с шагом 5 мм.
2. Выберите **Line**, **Rectangle** или **Circle**. Два щелчка задают концы
   линии, противоположные углы прямоугольника либо центр и радиус окружности.
   В меню **Curves → Three-point arc** укажите начало дуги, точку на дуге
   и конец. Для **Spline** укажите точки, через которые проходит кривая.
   Enter завершает открытый сплайн, щелчок по первой точке замыкает его.
   Средняя кнопка перемещает плоскость, колесо меняет масштаб.
3. Нажмите **Finish**. Для профиля нужен один замкнутый внешний контур.
   Внутри можно разместить отдельные замкнутые контуры для вырезов.
   **Undo** отменяет последний шаг внутри редактора, **Cancel** закрывает редактор
   с сохранением исходного состояния модели.
4. Выберите эскиз в **Model tree** и откройте **Model → Extrude sketch** или
   **Revolve sketch**. Выдавливание задаётся расстоянием со знаком.
   Вращение задаётся углом, осью U или V и её поперечным смещением.
   Ось может касаться края профиля, но не должна пересекать его.
5. Для булевой операции выберите первое тело в дереве и откройте
   **Model → Combine bodies**. Доступны объединение, вычитание и пересечение.
   После успеха исходные тела скрываются. Флажки в дереве управляют видимостью.

Дважды щёлкните по эскизу в дереве или выберите **Sketch → Edit sketch**,
чтобы изменить геометрию и размеры. **Finish** перестроит зависимые
операции. **Edit → Undo** вернёт исходный эскиз и зависимые тела.

В редакторе **Add constraint** добавляет совпадение точек, фиксацию точки,
горизонтальность, вертикальность, перпендикулярность и параллельность.
Касание связывает дугу или окружность с прямым отрезком, дугой или окружностью.
Равенство связывает длины прямых отрезков или радиусы круговых кривых.
Для симметрии выберите две точки и затем прямую ось. Через управляющий угол
задайте угол между направлениями двух прямых отрезков, от 0° без включения до 180°.

Дважды щёлкните по длине, диаметру или углу в списке ограничений, чтобы
изменить значение. Под списком показаны оставшиеся степени свободы,
полностью определённые элементы выделены зелёным. Конфликтующие ограничения
выделяются в списке. Редактор показывает последнюю корректную геометрию,
пока вы исправляете или удаляете конфликт.

Флажок **Construction geometry** делает выбранный или следующий построенный
элемент вспомогательным. Такие элементы отображаются штрихом, участвуют
в ограничениях и исключаются из контура профиля и маршрута траектории.

Для эскиза на детали выберите тело и вызовите **Sketch → New on planar face**.
Рёбра опорной грани показаны штрихом. При построении можно привязаться к их
точкам. Для существующей точки используйте **Link to projected edge**.
После изменения опорного тела ссылки обновляются при однозначном сопоставлении.
Если исходное ребро потеряно, дерево сообщает об ошибке, а зависимые операции
ожидают исправления. Привязку можно удалить и выбрать новое ребро в редакторе.

## Расширенное моделирование деталей

В меню **Create** создайте вспомогательную плоскость или ось по точке и
направлению. На выбранной плоскости создаётся эскиз через **Sketch → New on
construction plane**. Ось, лежащую в плоскости эскиза, можно выбрать в
диалоге вращения. Вспомогательная геометрия видна в дереве и исключается
из экспорта STEP и STL.

В меню **Model** доступны построение по траектории и по упорядоченным
сечениям. Для сечений используйте эскизы с одним замкнутым контуром.
Чтобы провести профиль по кривой, создайте отдельный эскиз, включите
**Path sketch** и соберите одну связную незамкнутую цепочку из отрезков,
дуг или сплайнов. Выберите профиль, затем **Model → Sweep along path**
и укажите эскиз траектории в **Path source**. Начало пути должно лежать
на плоскости профиля, а касательная в начале идти по её нормали.
Направление пути можно обратить в диалоге. Также путь можно задать
точками в координатах профиля. При построении оболочки выберите плоские грани для удаления и
толщину стенки. Для уклона выберите нейтральную грань, стенки и угол.
Двойной щелчок по операции в дереве открывает её параметры.

Для фаски или скругления нескольких рёбер выберите соответствующую
команду в **Model**, отметьте рёбра в 3D и нажмите Enter. Нажатие на
отмеченное ребро снимает его с выбора. В **Model → Measure** можно
измерить расстояние между вершинами одного тела или минимальный зазор
между телами. Там же отображаются объём и центр масс. Плотность
задаётся в кг/м³ для отдельного тела, масса рассчитывается в кг.

## Отверстия, фаски и скругления

В диалоге **Hole…** можно выбрать простое отверстие, цековку с плоским дном
или коническую зенковку. Диаметр, шаг, длина и направление метрической
резьбы передаются на связанный чертёж как условное обозначение. В 3D
строится отверстие; винтовой профиль резьбы не моделируется.

При обработке ребра можно включить поиск касательной цепочки. Для
скругления на открытой цепочке доступны начальный и конечный радиусы.
Двойной щелчок по операции в дереве открывает её параметры.

В меню **Model** команды **Move flat face…** и **Remove blend…** работают
и с телом, импортированным из STEP. Смещение поддерживает плоские грани
с соседними стенками, которые можно продолжить в направлении смещения.
Удаление скругления восстанавливает соседние поверхности, если ядро
может замкнуть их в корректное тело. Результат можно сохранить в STEP.

Выберите видимое твёрдое тело в дереве модели. В меню **Model** доступны:

- **Hole**. Щёлкните внутри плоской грани в центре будущего отверстия.
  Задайте диаметр и выберите **Through** для сквозного отверстия или
  укажите глубину для глухого. Глубина отсчитывается внутрь от выбранной грани.
- **Chamfer**. Щёлкните по одному острому ребру и задайте одинаковый отступ
  на обеих гранях.
- **Fillet**. Щёлкните по одному острому ребру и задайте радиус.

Правая кнопка вращает вид во время выбора, **Esc** отменяет выбор.
Результат появляется под исходным телом в дереве. Допускаются операции над
одним твёрдым телом. Для отверстия нужна плоская грань, а касательная цепочка
рёбер не обрабатывается как одно ребро.

В **Properties** можно изменить размеры и режим отверстия, отступ фаски
и радиус скругления. При перестроении привязка должна однозначно совпасть
с исходной гранью или ребром. Если геометрия сместилась или исчезла,
операция помечается **Invalid**. Можно отменить изменение либо создать
операцию с новым выбором.

## Массивы и зеркальное отражение

Команда **Model → Pattern individual operation…** повторяет изменение от
выбранной операции, например вырез отверстия с цековкой. Задайте линейный
шаг по XYZ или выберите готовый эскиз траектории с дугой или сплайном.
Экземпляры распределяются по длине эскиза с сохранением ориентации исходной
операции. Редактирование исходной операции перестраивает весь массив.

Выберите тело в дереве модели и откройте **Model → Transform body**.

- **Linear array** — ось X, Y или Z, количество экземпляров и шаг в миллиметрах.
  Отрицательный шаг меняет направление.
- **Circular array** — глобальная ось через начало координат, количество
  экземпляров и угол. Для неполного оборота крайние экземпляры расположены
  в начале и конце дуги. При 360° экземпляры равномерно распределены по окружности.
- **Mirror** — плоскость XY, XZ или YZ и её смещение вдоль нормали. Для XY
  смещение отсчитывается вдоль Z, для XZ вдоль Y, для YZ вдоль X.

Количество экземпляров массива включает оригинал и составляет от 2 до 100.
Копии остаются отдельными твёрдыми телами и могут пересекаться. При отражении
можно показать оригинал флажком в дереве. Параметры каждой операции доступны в
**Properties** и применяются кнопкой **Apply**.

## Сборки

В редакторе сборки, на вкладке **Mates**, можно задать расстояние или угол
между плоскостями, пределы линейного хода и винтовую связь. Для винтовой
связи сначала сопрягите винт с опорой, оставив вращение вокруг его оси.
Свяжите цилиндры каретки и винта, задайте ход за оборот и минимум/максимум.
Отрицательный ход меняет направление. В сборке поддерживается одна
винтовая связь.

Выберите сборку в дереве и откройте **Model → Assemblies → Move and check assembly…**.
Команда позволяет задать поворот винта или изменить размещение свободного
компонента. Предпросмотр показывает положение после применения сопряжений;
**Cancel** возвращает исходное состояние. На вкладке проверки движения
можно проверить от 2 до 50 положений. Столкновения между выбранными
положениями такой замер может пропустить.

На вкладке **Context and motion** можно связать плоскую грань экземпляра
с параллельной плоскостью другого компонента и задать зазор. При изменении
опоры грань перестраивается, а при потере ссылки дерево указывает проблемный
компонент. Изменение хранится в сборке и применяется к выбранному экземпляру.
Флаг **Simplified** показывает габаритный параллелепипед в 3D. Чтобы выбрать
грань, ребро или вершину в такой сборке, отключите упрощённый вид. Сопряжения,
чертежи, проверки пересечений и экспорт используют полную геометрию.

Сценарий для проверки: [винтовой узел](examples/screw-drive.graph3d).

Откройте **Model → Create assembly**. Задайте количество компонентов
и выберите исходное тело для каждой строки. Одно тело можно использовать
несколько раз. Сборка содержит от 2 до 100 компонентов и до 1000 твёрдых тел.

В столбце **Relative to** выберите начало сборки или более ранний компонент.
Координаты задаются в миллиметрах, повороты — в градусах вокруг X, Y и Z.
Размещение применяется к координатам исходного тела в модели. Система
координат компонента наследует перемещение и поворот выбранной опоры.
Повороты применяются в порядке X → Y → Z, затем добавляется смещение.
При создании сборки исходные тела скрываются. Их можно показать флажками
в дереве модели.

Выберите сборку и нажмите **Properties → Edit component placement**,
чтобы изменить размещение выбранных при создании тел. STEP переносит иерархию
и геометрию компонентов в рассчитанных положениях. Сопряжения хранятся в проекте Graph3D.

### Листовой металл

Откройте **Model → Sheet metal → New sheet part…** и задайте длину, ширину и толщину
основания. Для П-образного кронштейна добавьте два сгиба на разных сторонах.
Например, для основания 60 × 40 × 1,5 мм задайте полки 20 и 25 мм, радиус 2 мм,
угол 90°, коэффициент K = 0,42 и разгрузочные вырезы 1 мм. В таблице отверстий
задайте панель 2, координаты 12 и 18 мм и диаметр 6 мм.

**Check development** проверяет геометрию и показывает длину заготовки 113,26 мм
для этого примера. **Create flat drawing…** создаёт чертёж развёртки. Сохраните
изменённую модель и выполните **File → Update flat pattern from project** в
чертеже, чтобы обновить геометрию. **Export flat DXF…** записывает контур и
отверстия на слой `CUT`, а оси гибов на `BEND` в масштабе 1:1.

## Параметры и история

В **Model → Variables and variants…** задайте именованные переменные и
формулы. Например, `outer = 30`, `wall = 3`, `inner = outer - 2*wall`.
Чтобы связать формулу с размером, выберите эскиз или операцию в дереве и
заполните вкладку формул объекта. Для эскиза `dimension.N` — номер ограничения
в списке, начиная с 1. Формулы поддерживают арифметику, степени и скобки.
Ошибки имени, циклы, деление на ноль и недопустимая геометрия показываются
в диалоге. Последняя рабочая модель сохраняется.

Для семейства деталей добавьте именованные исполнения и укажите только
отличающиеся значения. Активное исполнение сохраняется в проекте. При
привязке чертежа к модели выберите конкретное исполнение, базовые значения
или следование за активным исполнением модели. Обновление чертежа сохраняет
этот выбор.

- Выберите **Extrude**, **Revolve**, **Hole**, **Chamfer** или **Fillet** в дереве. В панели **Properties**
  измените параметры и нажмите **Apply**. Перестраиваются выбранная операция
  и все операции, которые используют её результат.
- Ошибочная операция помечается **Invalid**, зависимые от неё операции
  помечаются **Blocked**. Их старые тела скрываются, чтобы не показывать
  результат от прежних параметров. Исправьте параметры или отмените изменение.
- **Edit → Undo / Redo** восстанавливает создание эскизов и тел, параметры,
  видимость и очистку сцены. История отмены хранится до закрытия или открытия проекта.

## Файлы

- **File → Save project / Open project** сохраняет и открывает файлы `.graph3d`
  с параметрами операций и видимостью тел.
- **File → Import STEP / Export visible bodies to STEP** переносит точную геометрию,
  вложенность сборок, имена и цвета компонентов. Имя и цвет можно задать в свойствах компонента.
- **File → Import IGES / Export visible bodies to IGES** переносит твёрдые тела
  и замкнутые оболочки. При экспорте используются миллиметры.
- **File → Import STL** загружает треугольную сетку. Укажите число миллиметров в
  единице исходного файла, например 25,4 для дюймов. **Export visible bodies to STL**
  записывает сетку видимых твёрдых тел в миллиметрах.

Сведения о единицах и ограничениях приведены в [описании формата](docs/project-format.md).

### Связанные детали и сопряжения

В меню **Model → Assemblies** команда **Insert component from file** вставляет
тело или подсборку из `.graph3d`. Затем включите вставленные объекты в
**Create assembly**. Сборка хранит геометрию последнего обновления и открывается
при недоступном исходнике. Команды **Update selected component** и
**Update all linked components** перечитывают исходные файлы и вложенные
связи. Перемещённый источник можно выбрать заново. Обновление отменяется
одним шагом Undo.

В окне сборки отметьте базовый компонент как **Fixed**. На вкладке **Mates**
добавьте совпадение плоских граней или соосность цилиндров. Сопряжение
перемещает компонент относительно более раннего компонента в таблице.
Проверка показывает оставшиеся степени свободы относительно текущего
положения опорных компонентов и выделяет конфликтующее сопряжение.
Для исправления потерянной ссылки удалите сопряжение и укажите поверхности
заново.

Команда **Check component interference** показывает пары тел с ненулевым
объёмом пересечения, включая тела во вложенных подсборках. В **Component
properties** задаются обозначение, название, материал и примечание.
Их можно посмотреть в иерархии **Assembly structure**.

### Сборочный чертёж и спецификация

Для отдельного документа выберите **File → New specification** или
**Assembly drawing → Create specification document…** на чертеже.
Файл `.g3spec` хранит связь со сборкой, выбранное исполнение и лист чертежа.
В таблице можно менять разделы, наименование, материал, примечания и
количество, а также добавлять ручные строки. **Refresh from assembly**
обновляет количества строк из модели и сохраняет их номера и оформление.
**Compare model, table and drawing…** показывает расхождения, включая
потерянные или отсутствующие обозначения на листе.

На чертеже выберите **Assembly drawing → Link specification document…**.
После изменения сборки сохраните модель, обновите спецификацию и сохраните её,
затем нажмите **Update from model** на чертеже. Номера выносок изменятся
вместе с позициями заменённых экземпляров крепежа. Спецификацию можно
отдельно экспортировать в PDF или CSV с разделителем «точка с запятой».

Крепёж добавляется через **Model → Assemblies → Insert catalog fastener…**.
Доступны шестигранные болты и гайки и плоские шайбы M4, M5, M6, M8, M10 и M12.
Для болта можно выбрать длину. Каталог использует обозначения Graph3D и
упрощённую геометрию без винтового профиля. Чтобы заменить часть одинаковых
болтов, вставьте нужный типоразмер и укажите его для выбранных строк сборки.

В редакторе чертежа выберите сборку через **Model views → Insert from model
or change source**. Меню **Assembly drawing** открывает таблицу с обозначением,
наименованием, материалом, количеством и примечанием. Повторные экземпляры
одного объекта или одной связанной детали с общим исходником объединяются
в строку. Для вложенной подсборки самостоятельной позицией считается сама
подсборка, а её детали можно посмотреть в чертеже подсборки.

Выберите **Place position number**, строку спецификации, вид и экземпляр.
Укажите точку на детали и место для номера. Затем сохраните комплект в
`.g3draw`. При изменении состава сборки сохраните модель и выполните
**Update from model** на листе чертежа. Прежние позиции сохраняют свои номера.
При экспорте PDF спецификация добавляется после чертежей отдельными листами
А4. Её включение можно настроить для каждого листа чертежа.

## Самостоятельные 2D-чертежи

На стартовой странице выберите **New drawing** или откройте **Drawing →
New 2D drawing**. Редактор открывается с пустым листом. В **Sheet → Format
and title block** можно выбрать A4 или A3 в альбомной ориентации и заполнить
название, номер и поле автора.

Стройте отрезки, прямоугольники и окружности на листе. При построении
доступны привязки к узлам, центрам и четвертям окружностей, а также шаг 1 мм.
Для горизонтального или вертикального размера укажите две точки и
положение размерной линии. Квадрат у курсора отмечает привязку к концу
отрезка, углу прямоугольника, центру или крайней точке окружности.
Такая точка следует за геометрией, а точка на пустом месте остаётся на листе.
При удалении фигуры размер сохраняет её последние координаты. **Undo**
восстанавливает фигуру и привязку.
В режиме **Select** элементы можно перетаскивать, удалять и редактировать
через **Item properties** с точностью ввода до 0,001 мм. Колесо меняет
масштаб просмотра, средняя кнопка перемещает лист, а **F** вписывает его
в окно. Поддерживаются сплошные, штриховые и осевые линии и текстовые заметки.

**File → Save** сохраняет редактируемый файл `.g3draw`. Его можно открыть
через список недавних файлов или через **Open**. Чертежи с привязками
сохраняются в формате v2. Старые чертежи v1 открываются с обычными размерами. **Export PDF** выпускает
векторный лист в масштабе 1:1. Основная надпись пока базовая.

Меню **Лист** добавляет и удаляет листы, настраивает А4 или А3 и их ориентацию.
Вкладки переключают листы, отмена возвращает к листу затронутой операции.
PDF включает все вкладки в том же порядке. При выборе основной надписи по ЕСКД
для А4 используется книжная ориентация.
[ГОСТ Р 2.104-2023, приложение Б](https://meganorm.ru/Data/816/81679.pdf)

В меню **Слои** можно управлять видимостью и блокировкой слоёв, а также
переносить объекты на активный слой. Меню **Обозначения** добавляет
выноски, базы, рамки допусков и обозначения шероховатости. Технические
требования задаются отдельными пунктами на листе и печатаются над
основной надписью.
[ГОСТ Р 2.316-2023](https://protect.gost.ru/gost/details/25054f20-f35a-45ff-8d1f-1c198c35ea06)
[ГОСТ Р 2.308-2023](https://protect.gost.ru/gost/details/41ac4e79-c383-42de-bae3-88f76054b981)
[ГОСТ 2.309-73](https://protect.gost.ru/gost/details/757ee9f1-6974-4c87-b285-45b3719ca5e7)

В меню **Виды модели** можно настроить масштаб каждого вида, указать
линию разреза щелчком на опорном виде, ограничить местный разрез волнистой
границей и создать выносной элемент с собственным масштабом.
[ГОСТ 2.305-2008, разделы 6 и 8](https://rosgosts.ru/file/gost/01/100/gost_2.305-2008.pdf)

Шаблон основной надписи включает сетку, основные реквизиты и номера листов.
Организационные подписи, учётные дополнительные графы и нормоконтроль
оформляют отдельно. Дополнительные местные разрезы и выносные элементы
можно добавить через **Model views → Arrange and add views…**.

В чертеже и в эскизе после первой точки инструмента **Line** можно
указать длину в миллиметрах и угол в градусах. Положительный угол
отсчитывается против часовой стрелки от горизонтальной оси. Нажмите
**Add line** или **Enter**, чтобы построить отрезок.

### Дуги, обработка контуров и размеры

- **Geometry → Three-point arc** строит дугу по началу, промежуточной
  точке и концу. Для **Polyline** укажите вершины, нажмите Enter для
  завершения или щёлкните по первой вершине для замыкания.
- **Modify → Trim** удаляет указанный участок между пересечениями или
  между пересечением и концом. **Extend** продлевает выбранный конец
  открытой кривой до ближайшей границы. **Parallel offset** создаёт копию
  со знаковым смещением. У дуг и окружностей плюс увеличивает радиус,
  а у отрезков и полилиний смещает влево по направлению построения.
- При наведении доступны середины, пересечения и ближайшие точки на кривых.
  В **Dimensions** доступны наклонный линейный, угловой, радиальный
  и диаметральный размеры. Для угла укажите вершину и точки на двух лучах.
  Для радиуса или диаметра щёлкните по окружности или дуге и разместите
  надпись. Размеры пересчитываются при изменении привязанной геометрии.
- **Geometry → Hatch** штрихует область по щелчку внутри неё. Можно использовать
  замкнутую полилинию, окружность, прямоугольник или контур из соединённых
  кривых. Внутренние отверстия остаются пустыми. Новая штриховка следует
  за границами. Если контур разомкнулся или опора исчезла, чертёж показывает
  отметку о потерянной границе.

### Фрагменты, таблицы и шаблоны

- В меню **Geometry** доступны **Ellipse**, **Spline** и **Construction line**.
  Эллипс задаётся противоположными углами габарита. Сплайн проходит через
  выбранные точки. Нажмите Enter для завершения или щёлкните по первой точке,
  чтобы замкнуть его. Вспомогательные прямые служат опорами на рабочем листе.
- **Save visible objects as fragment…** сохраняет видимую ручную геометрию
  в `.g3frag`. Через **Insert fragment…** файл можно вставлять повторно.
  Каждая вставка выбирается и перемещается целиком.
- В меню **Annotations** доступны таблица, обозначения резьбы и сварного шва.
  В **Item properties** у размера можно задать код посадки и оба предельных
  отклонения. У сварного шва можно выбрать сторону полки. Значения вводятся
  вручную. [Предельные отклонения](https://protect.gost.ru/gost/details/62de9da6-e1a7-4023-955e-7dd9777eaab6) · [Изображение резьбы](https://protect.gost.ru/gost/details/75b396ab-4b3e-4305-a871-9809188c6bc4)
- В меню **Sheet → Edit custom title block…** задайте ширину, строки и поля
  основной надписи. Опция **Use linked model title, designation and mass**
  подставляет доступные поля из последней версии связанной модели.
  **Save drawing template…** записывает настройки всех листов в `.g3template`.
  **New from drawing template…** открывает новый чертёж с этими настройками.

Для новых объектов и привязок используется `.g3draw` v7. Файлы v1–v6
поддерживаются. Изменения можно отменять и повторять.

## Чертёж со связью на модель

Сохраните деталь в `.graph3d`. На стартовой странице выберите **New drawing**,
затем **Model views → Insert from model or change source**. Выберите файл
и твёрдое тело. Программа добавит три исходных вида на лист, где можно
рисовать, проставлять размеры и добавлять заметки.

В **View layout and section** задайте центр каждого вида в миллиметрах от
левого верхнего угла листа и коэффициент масштаба. Например, 0,5 даёт 1:2.
Можно включить один полный разрез A–A по плоскости XZ, XY или YZ, задать
его смещение и переключить автоматические размеры и невидимые линии.

В **Arrange and add views…** можно перемещать, скрывать и добавлять виды,
включая изометрию, произвольный ракурс, проекционный вид и вид по стрелке.
Для ступенчатого или ломаного разреза выберите опорный вид и задайте точки
линии разреза. Указывайте пары X и Y по одной на строку. X направлена вправо,
Y вверх, отсчёт ведётся от центра опорного вида в миллиметрах модели.
В том же диалоге можно добавить несколько выносных элементов и местных
разрезов. Размещение и масштаб каждого вида сохраняются с чертежом.

Для ручного линейного размера выберите две точки на одном виде. Для радиуса
или диаметра выберите дугу или окружность. Значение показывается в
миллиметрах модели даже на виде 1:2. При потере опоры размер помечается
надписью **Lost link**. Выберите его и вызовите **Edit → Reattach dimension to view…**,
чтобы указать опору заново.

Сохраните чертёж как `.g3draw`. После правки и сохранения модели используйте
**Update from model**. Обновляются виды, разрезы и размеры с доступными
опорами. Ручное оформление сохраняет размещение.
При ошибке обновления на листе остаётся последняя успешная версия видов,
а строка под листом сообщает о состоянии источника. Если источник переместился,
укажите его через ту же команду вставки. Экспорт PDF включает модели и
ручное оформление листа, в том числе сохранённую версию видов при недоступном источнике.

## Чертёж выбранного тела

Выберите корректное тело в дереве и откройте **Drawing → Create drawing
from selected body**. Лист A4 содержит виды спереди, сверху и справа
в одинаковом масштабе по методу первого угла. Есть рамка, основная надпись,
габариты по X, Y и Z, центровые метки и диаметры полных видимых окружностей
на виде сверху. Одинаковые диаметры группируются. **Save PDF** сохраняет
векторный лист. Штриховые линии и размеры можно переключать.

Чертёж создаётся из текущей геометрии. После изменения модели откройте
чертёж заново. Автоматически показывается до пяти групп диаметров. Для
частичных дуг, фасок и ручного нанесения размеров инструментов пока нет.
Рамка и основная надпись предназначены для демонстрации.

В окне чертежа **Section plane** включает полный разрез A–A. Можно
выбрать плоскость XZ, XY или YZ и указать смещение от центра габаритов
тела в миллиметрах. Разрез занимает место соответствующего вида, а
на соседнем виде отображаются линия сечения и стрелки. Полости остаются
пустыми. Предпросмотр и PDF используют один лист. Настройки разреза
задаются заново при открытии окна чертежа.

Готовые проекты и повторяемый сценарий построения фланца приведены
в [демонстрационных моделях](examples/README.md).

## Сборка на Windows

Установите [MSYS2](https://www.msys2.org/) и откройте терминал **MSYS2 UCRT64**.
Обновите среду командой `pacman -Syu`. Если MSYS2 попросит закрыть терминал,
откройте его снова и повторите команду обновления.

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,qt6-base,opencascade}
```

В том же терминале перейдите в папку проекта. Например, для
`C:\Projects\Graph3D` выполните `cd /c/Projects/Graph3D`. Затем:

```bash
cmake --preset dev
cmake --build --preset dev
ctest --preset dev
./build/dev/Graph3D.exe
```

Запускайте программу из UCRT64, чтобы в пути поиска были DLL этой среды.
Пакеты Qt и OCCT должны быть из одной среды с компилятором. Для сборки нужны
C++20, CMake 3.24 или новее, Ninja, Qt 6.5–6.x и OCCT 7.9 или новее в ветке 7.x.

Автоматические тесты проверяют геометрию, включая операции над гранями и рёбрами, перестроение, Undo/Redo и обмен
файлами. На интерактивном рабочем столе Windows можно дополнительно
проверить управление камерой, моделирование, работу с файлами и экспорт чертежа через окно:

```bash
cmake --preset dev -DGRAPH3D_GUI_TESTS=ON
cmake --build --preset dev
ctest --preset dev
```

Этот тест требует рабочий OpenGL и видимое окно. Сборка на Linux пока не проверена.

### Сборка установщика

Установите Inno Setup 6 для текущего пользователя. В терминале **MSYS2 UCRT64**
соберите Release и подготовьте библиотеки FFmpeg (LGPL) и LibTIFF (без JBIG):

```bash
pacman -S --needed make diffutils
cmake -S . -B build/release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/release
mkdir -p build/installers/ffmpeg-src
curl -fL https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz -o build/installers/ffmpeg-src/ffmpeg-9.0.2.tar.xz
bash packaging/windows/build-ffmpeg.sh build/installers/ffmpeg-src/ffmpeg-9.0.2.tar.xz build/installers/ffmpeg-src

mkdir -p build/installers/tiff-src
curl -fL https://download.osgeo.org/libtiff/tiff-4.7.2.tar.gz -o build/installers/tiff-src/tiff-4.7.2.tar.gz
echo '672bd7d10aee4606171afb864f3570b83340f6a33e2c186dc0512f7145ffdf6a  build/installers/tiff-src/tiff-4.7.2.tar.gz' | sha256sum -c -
tar -xf build/installers/tiff-src/tiff-4.7.2.tar.gz -C build/installers/tiff-src
cmake -S build/installers/tiff-src/tiff-4.7.2 -B build/installers/tiff-src/build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=ON -Djbig=OFF -Dtiff-tools=OFF \
  -Dtiff-tests=OFF -Dtiff-contrib=OFF -Dtiff-docs=OFF -Dtiff-cxx=OFF
cmake --build build/installers/tiff-src/build --target tiff
```

Затем из папки проекта в PowerShell:

```powershell
.\packaging\windows\package.ps1 -Version 0.1.0
```

В `build/installers` появятся установщик, контрольная сумма SHA-256 и список
поставляемых библиотек со ссылками на исходники. Если Inno Setup или MSYS2
установлены в другую папку, используйте параметры `-InnoCompiler` и `-MsysRoot`.

Лицензия Graph3D ещё не выбрана. Сведения о прямых зависимостях см.
в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
