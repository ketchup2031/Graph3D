# Graph3D

Graph3D — проект параметрической CAD-системы для механического проектирования.
Прототип показывает интерактивную 3D-сцену на базе Open CASCADE Technology (OCCT).
План следующих этапов приведён в [дорожной карте](Graph3D_Development_Plan.md).

## Стартовая страница

При запуске Graph3D открывается стартовая страница. В **Open** можно выбрать
файл или вернуться к одному из восьми недавних проектов. В **Create** доступны
пустая деталь, эскиз на XY и демонстрационный куб. Встроенные примеры показывают
виды детали и открываются для сохранения в новый файл.

**File → Start page** возвращает на стартовую страницу из редактора.
**Return to model** открывает текущий проект вместе с несохранёнными изменениями.

В меню **Settings → Dark theme** можно переключить оформление. Graph3D
запоминает этот выбор при следующем запуске.

Английский интерфейс включён по умолчанию. Для русского языка выберите
**Settings → Language → Русский** и перезапустите Graph3D. Для возврата к
английскому используйте **Настройки → Язык → English**.

## 3D-сцена

- В меню **Create** можно добавить куб, цилиндр или сферу. Новые тела
  располагаются рядом друг с другом.
- Левый щелчок выбирает тело, правая кнопка вращает камеру, средняя перемещает
  её, колесо масштабирует. Клавиша **F** показывает все тела.
- В меню **View** доступны стандартные виды, оси и сетка.
- **File → New scene** очищает сцену. **Help → Open log folder** открывает журнал.

Для сохранения сцены используйте **File → Save project**.

## Эскизы и моделирование

1. В **Sketch** выберите плоскость XY, XZ или YZ. На ней U — горизонтальная
   координата, V — вертикальная. Сетка привязывает точки с шагом 5 мм.
2. Выберите **Line**, **Rectangle** или **Circle**. Два щелчка задают концы
   линии, противоположные углы прямоугольника либо центр и радиус окружности.
   Средняя кнопка перемещает плоскость, колесо меняет масштаб.
3. Нажмите **Finish**. Для профиля нужен один замкнутый внешний контур.
   Внутри можно разместить отдельные замкнутые контуры для вырезов.
   **Undo** отменяет последний шаг внутри редактора, **Cancel** закрывает редактор
   с сохранением исходного состояния модели.
4. Выберите эскиз в **Model tree** и откройте **Model → Extrude sketch** или
   **Revolve sketch**. Выдавливание задаётся расстоянием со знаком.
   Вращение задаётся углом, осью U или V и её поперечным смещением.
   Ось может касаться края профиля, но не должна пересекать его.
5. Для булевой операции выберите первое тело в дереве и откройте
   **Model → Combine bodies**. Доступны объединение, вычитание и пересечение.
   После успеха исходные тела скрываются. Флажки в дереве управляют видимостью.

Дважды щёлкните по эскизу в дереве или выберите **Sketch → Edit sketch**,
чтобы изменить геометрию и размеры. **Finish** перестроит зависимые
операции. **Edit → Undo** вернёт исходный эскиз и зависимые тела.

В редакторе **Add constraint** добавляет совпадение точек, горизонтальность,
вертикальность, перпендикулярность, управляющую длину и диаметр. Для изменения
размера дважды щёлкните по нему в списке ограничений. Редактор подсвечивает
невыполненные ограничения. При конфликте исправьте или удалите ограничение.

Для эскиза на детали выберите тело и вызовите **Sketch → New on planar face**.
Рёбра опорной грани показаны штрихом. При построении можно привязаться к их
точкам. Для существующей точки используйте **Link to projected edge**.
После изменения опорного тела ссылки обновляются при однозначном сопоставлении.
Если исходное ребро потеряно, дерево сообщает об ошибке, а зависимые операции
ожидают исправления. Привязку можно удалить и выбрать новое ребро в редакторе.

## Отверстия, фаски и скругления

Выберите видимое твёрдое тело в дереве модели. В меню **Model** доступны:

- **Hole**. Щёлкните внутри плоской грани в центре будущего отверстия.
  Задайте диаметр и выберите **Through** для сквозного отверстия или
  укажите глубину для глухого. Глубина отсчитывается внутрь от выбранной грани.
- **Chamfer**. Щёлкните по одному острому ребру и задайте одинаковый отступ
  на обеих гранях.
- **Fillet**. Щёлкните по одному острому ребру и задайте радиус.

Правая кнопка вращает вид во время выбора, **Esc** отменяет выбор.
Результат появляется под исходным телом в дереве. Допускаются операции над
одним твёрдым телом. Для отверстия нужна плоская грань, а касательная цепочка
рёбер не обрабатывается как одно ребро.

В **Properties** можно изменить размеры и режим отверстия, отступ фаски
и радиус скругления. При перестроении привязка должна однозначно совпасть
с исходной гранью или ребром. Если геометрия сместилась или исчезла,
операция помечается **Invalid**. Можно отменить изменение либо создать
операцию с новым выбором.

## Массивы и зеркальное отражение

Выберите тело в дереве модели и откройте **Model → Transform body**.

- **Linear array** — ось X, Y или Z, количество экземпляров и шаг в миллиметрах.
  Отрицательный шаг меняет направление.
- **Circular array** — глобальная ось через начало координат, количество
  экземпляров и угол. Для неполного оборота крайние экземпляры расположены
  в начале и конце дуги. При 360° экземпляры равномерно распределены по окружности.
- **Mirror** — плоскость XY, XZ или YZ и её смещение вдоль нормали. Для XY
  смещение отсчитывается вдоль Z, для XZ вдоль Y, для YZ вдоль X.

Количество экземпляров массива включает оригинал и составляет от 2 до 100.
Копии остаются отдельными твёрдыми телами и могут пересекаться. При отражении
можно показать оригинал флажком в дереве. Параметры каждой операции доступны в
**Properties** и применяются кнопкой **Apply**.

## Сборки

Откройте **Model → Create assembly**. Задайте количество компонентов
и выберите исходное тело для каждой строки. Одно тело можно использовать
несколько раз. Сборка содержит от 2 до 100 компонентов и до 1000 твёрдых тел.

В столбце **Relative to** выберите начало сборки или более ранний компонент.
Координаты задаются в миллиметрах, повороты — в градусах вокруг X, Y и Z.
Размещение применяется к координатам исходного тела в модели. Система
координат компонента наследует перемещение и поворот выбранной опоры.
Повороты применяются в порядке X → Y → Z, затем добавляется смещение.
При создании сборки исходные тела скрываются. Их можно показать флажками
в дереве модели.

Выберите сборку и нажмите **Properties → Edit component placement**,
чтобы изменить размещение выбранных при создании тел. STEP переносит
геометрию в рассчитанных положениях. Список компонентов и жёсткие связи
сохраняются в проекте Graph3D.

## Параметры и история

- Выберите **Extrude**, **Revolve**, **Hole**, **Chamfer** или **Fillet** в дереве. В панели **Properties**
  измените параметры и нажмите **Apply**. Перестраиваются выбранная операция
  и все операции, которые используют её результат.
- Ошибочная операция помечается **Invalid**, зависимые от неё операции
  помечаются **Blocked**. Их старые тела скрываются, чтобы не показывать
  результат от прежних параметров. Исправьте параметры или отмените изменение.
- **Edit → Undo / Redo** восстанавливает создание эскизов и тел, параметры,
  видимость и очистку сцены. История отмены хранится до закрытия или открытия проекта.

## Файлы

- **File → Save project / Open project** сохраняет и открывает файлы `.graph3d`
  с параметрами операций и видимостью тел.
- **File → Export visible bodies to STEP / STL** записывает видимые тела.
  STEP сохраняет точную геометрию, STL записывает сетку.
- **File → Import STEP** добавляет твёрдые тела в дерево как один импортированный
  объект. После сохранения проекта исходный STEP больше не нужен.

Сведения о единицах и ограничениях приведены в [описании формата](docs/project-format.md).

## Самостоятельные 2D-чертежи

На стартовой странице выберите **New drawing** или откройте **Drawing →
New 2D drawing**. Редактор открывается с пустым листом. В **Sheet → Format
and title block** можно выбрать A4 или A3 в альбомной ориентации и заполнить
название, номер и поле автора.

Стройте отрезки, прямоугольники и окружности на листе. При построении
доступны привязки к узлам, центрам и четвертям окружностей, а также шаг 1 мм.
Для горизонтального или вертикального размера укажите две точки и
положение размерной линии. Квадрат у курсора отмечает привязку к концу
отрезка, углу прямоугольника, центру или крайней точке окружности.
Такая точка следует за геометрией, а точка на пустом месте остаётся на листе.
При удалении фигуры размер сохраняет её последние координаты. **Undo**
восстанавливает фигуру и привязку.
В режиме **Select** элементы можно перетаскивать, удалять и редактировать
через **Item properties** с точностью ввода до 0,001 мм. Колесо меняет
масштаб просмотра, средняя кнопка перемещает лист, а **F** вписывает его
в окно. Поддерживаются сплошные, штриховые и осевые линии и текстовые заметки.

**File → Save** сохраняет редактируемый файл `.g3draw`. Его можно открыть
через список недавних файлов или через **Open**. Чертежи с привязками
сохраняются в формате v2. Старые чертежи v1 открываются с обычными размерами. **Export PDF** выпускает
векторный лист в масштабе 1:1. Основная надпись пока базовая.

Меню **Лист** добавляет и удаляет листы, настраивает А4 или А3 и их ориентацию.
Вкладки переключают листы, отмена возвращает к листу затронутой операции.
PDF включает все вкладки в том же порядке. При выборе основной надписи по ЕСКД
для А4 используется книжная ориентация.
[ГОСТ Р 2.104-2023, приложение Б](https://meganorm.ru/Data/816/81679.pdf)

В меню **Слои** можно управлять видимостью и блокировкой слоёв, а также
переносить объекты на активный слой. Меню **Обозначения** добавляет
выноски, базы, рамки допусков и обозначения шероховатости. Технические
требования задаются отдельными пунктами на листе и печатаются над
основной надписью.
[ГОСТ Р 2.316-2023](https://protect.gost.ru/gost/details/25054f20-f35a-45ff-8d1f-1c198c35ea06)
[ГОСТ Р 2.308-2023](https://protect.gost.ru/gost/details/41ac4e79-c383-42de-bae3-88f76054b981)
[ГОСТ 2.309-73](https://protect.gost.ru/gost/details/757ee9f1-6974-4c87-b285-45b3719ca5e7)

В меню **Виды модели** можно настроить масштаб каждого вида, указать
линию разреза щелчком на опорном виде, ограничить местный разрез волнистой
границей и создать выносной элемент с собственным масштабом.
[ГОСТ 2.305-2008, разделы 6 и 8](https://rosgosts.ru/file/gost/01/100/gost_2.305-2008.pdf)

Шаблон основной надписи включает сетку, основные реквизиты и номера листов.
Организационные подписи, учётные дополнительные графы и нормоконтроль
оформляют отдельно. На каждом листе доступны один местный разрез и один
выносной элемент связанной модели.

В чертеже и в эскизе после первой точки инструмента **Line** можно
указать длину в миллиметрах и угол в градусах. Положительный угол
отсчитывается против часовой стрелки от горизонтальной оси. Нажмите
**Add line** или **Enter**, чтобы построить отрезок.

### Дуги, обработка контуров и размеры

- **Geometry → Three-point arc** строит дугу по началу, промежуточной
  точке и концу. Для **Polyline** укажите вершины, нажмите Enter для
  завершения или щёлкните по первой вершине для замыкания.
- **Modify → Trim** удаляет указанный участок между пересечениями или
  между пересечением и концом. **Extend** продлевает выбранный конец
  открытой кривой до ближайшей границы. **Parallel offset** создаёт копию
  со знаковым смещением. У дуг и окружностей плюс увеличивает радиус,
  а у отрезков и полилиний смещает влево по направлению построения.
- При наведении доступны середины, пересечения и ближайшие точки на кривых.
  В **Dimensions** доступны наклонный линейный, угловой, радиальный
  и диаметральный размеры. Для угла укажите вершину и точки на двух лучах.
  Для радиуса или диаметра щёлкните по окружности или дуге и разместите
  надпись. Размеры пересчитываются при изменении привязанной геометрии.
- **Geometry → Hatch** штрихует область по щелчку внутри неё. Можно использовать
  замкнутую полилинию, окружность, прямоугольник или контур из соединённых
  кривых. Внутренние отверстия остаются пустыми. Штриховка сохраняет контуры
  на момент построения. После изменения границ её можно построить заново.

Для новых объектов и привязок используется `.g3draw` v4. Старые файлы
открываются как раньше. Операции доступны в Undo/Redo и попадают в PDF.

## Чертёж со связью на модель

Сохраните деталь в `.graph3d`. На стартовой странице выберите **New drawing**,
затем **Model views → Insert from model or change source**. Выберите файл
и твёрдое тело. Три вида располагаются на том же листе, где можно рисовать
и добавлять обычные заметки.

В **View layout and section** задайте центр каждого вида в миллиметрах от
левого верхнего угла листа и коэффициент масштаба. Например, 0,5 даёт 1:2.
Можно включить один полный разрез A–A по плоскости XZ, XY или YZ, задать
его смещение и переключить автоматические размеры и невидимые линии.

Сохраните чертёж как `.g3draw`. После правки и сохранения модели используйте
**Update from model**. Обновляются виды, разрез и автоматические размеры.
Ручные 2D-элементы сохраняют положение и свои существующие привязки.
При ошибке обновления на листе остаётся последняя успешная версия видов,
а строка под листом сообщает о состоянии источника. Если источник переместился,
укажите его через ту же команду вставки. Экспорт PDF включает модели и
ручное оформление листа, в том числе сохранённую версию видов при недоступном источнике.

## Чертёж выбранного тела

Выберите корректное тело в дереве и откройте **Drawing → Create drawing
from selected body**. Лист A4 содержит виды спереди, сверху и справа
в одинаковом масштабе по методу первого угла. Есть рамка, основная надпись,
габариты по X, Y и Z, центровые метки и диаметры полных видимых окружностей
на виде сверху. Одинаковые диаметры группируются. **Save PDF** сохраняет
векторный лист. Штриховые линии и размеры можно переключать.

Чертёж создаётся из текущей геометрии. После изменения модели откройте
чертёж заново. Автоматически показывается до пяти групп диаметров. Для
частичных дуг, фасок и ручного нанесения размеров инструментов пока нет.
Рамка и основная надпись предназначены для демонстрации.

В окне чертежа **Section plane** включает полный разрез A–A. Можно
выбрать плоскость XZ, XY или YZ и указать смещение от центра габаритов
тела в миллиметрах. Разрез занимает место соответствующего вида, а
на соседнем виде отображаются линия сечения и стрелки. Полости остаются
пустыми. Предпросмотр и PDF используют один лист. Настройки разреза
задаются заново при открытии окна чертежа.

Готовые проекты и повторяемый сценарий построения фланца приведены
в [демонстрационных моделях](examples/README.md).

## Сборка на Windows

Установите [MSYS2](https://www.msys2.org/) и откройте терминал **MSYS2 UCRT64**.
Обновите среду командой `pacman -Syu`. Если MSYS2 попросит закрыть терминал,
откройте его снова и повторите команду обновления.

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,qt6-base,opencascade}
```

В том же терминале перейдите в папку проекта. Например, для
`C:\Projects\Graph3D` выполните `cd /c/Projects/Graph3D`. Затем:

```bash
cmake --preset dev
cmake --build --preset dev
ctest --preset dev
./build/dev/Graph3D.exe
```

Запускайте программу из UCRT64, чтобы в пути поиска были DLL этой среды.
Пакеты Qt и OCCT должны быть из одной среды с компилятором. Для сборки нужны
C++20, CMake 3.24 или новее, Ninja, Qt 6.5–6.x и OCCT 7.9 или новее в ветке 7.x.

Автоматические тесты проверяют геометрию, включая операции над гранями и рёбрами, перестроение, Undo/Redo и обмен
файлами. На интерактивном рабочем столе Windows можно дополнительно
проверить управление камерой, моделирование, работу с файлами и экспорт чертежа через окно:

```bash
cmake --preset dev -DGRAPH3D_GUI_TESTS=ON
cmake --build --preset dev
ctest --preset dev
```

Этот тест требует рабочий OpenGL и видимое окно. Сборка на Linux пока не проверена.

Лицензия Graph3D ещё не выбрана. Сведения о прямых зависимостях см.
в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
